## 📖 Sobre o documento

O whitepaper **"Visão Geral da Amazon Web Services"** apresenta os conceitos fundamentais da computação em nuvem e um panorama completo dos serviços da Nuvem AWS. É leitura essencial para quem está começando na plataforma ou se preparando para certificações como a **AWS Certified Cloud Practitioner**.

### Tópicos abordados

- ☁️ **Fundamentos de nuvem** — IaaS, PaaS, SaaS e modelos de implantação
- 🖥️ **Computação** — EC2, Lambda, Elastic Beanstalk e mais
- 📦 **Contêineres** — ECS, EKS, Fargate
- 🗄️ **Banco de dados** — RDS, DynamoDB, Aurora, Redshift
- 💾 **Armazenamento** — S3, EBS, EFS, Glacier
- 🌐 **Redes e entrega de conteúdo** — VPC, CloudFront, Route 53
- 🔐 **Segurança, identidade e conformidade** — IAM, KMS, Shield, WAF
- 🤖 **Machine Learning** — SageMaker e serviços de IA
- 🛠️ **Ferramentas de desenvolvedor** — CodeCommit, CodeBuild, CodeDeploy, CodePipeline
- 📊 **Gerenciamento e governança** — CloudWatch, CloudTrail, Config, Systems Manager
- 💰 **Gestão de custos** — Cost Explorer, Budgets, Pricing Calculator
- 📱 **Mobile, IoT, Game Tech, Mídia, Blockchain, Computação Quântica e Satélite**
- 🚀 **Migração e transferência de dados**
- ➡️ **Próximas etapas e recursos adicionais**
